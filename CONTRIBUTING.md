# Contributing

Thank you for showing interest in contributing to Xenon Emulator.

Before making any changes, do take a look at README.md for project information and how it works.

## Making Changes
To make any changes, follow the steps below:
1. Fork this repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes locally to see if it works.
5. Submit a _Pull Request_ to this repository.

Please make sure to follow the existing coding style that is already in the project as to avoid confusion.

## Issues
If you find any issues or bugs, or have a feature request for the emulator:
* Check existing issues first (to avoid duplicates)
* Provide as much detail as possible so it is easier to identify the issue / add your requested feature if applicable.

If you have any questions, please open a **Discussion** or **Issue** in this repository.
