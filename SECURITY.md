# Security Policy

## Reporting Vulnerabilities

If you happen to discover a potential security vulnerability in this project, please report it privately.
**DO NOT** open a public issue for security related problems as it risks the potential of attackers seeing it _before_ it gets fixed.

If you make a security vulnerability report, *please* include:
* A description of the vulnerability
* Steps to reproduce said issue (to find out how it is caused and how to fix it)
* The impact that this issue can cause,
* ...and any suggested fixes for said vulnerability if available.

I will review security reports as soon as possible and will work to address confirmed vulnerabilities.
